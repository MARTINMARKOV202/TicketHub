# TicketHub

Базов frontend проект за управление на заявки за техническа поддръжка и срокове за реакция.

## Стартиране

Отвори `index.html` в браузър или използвай VS Code Live Server. Няма нужда от инсталиране на зависимости.

## Функционалности

- Създаване на заявка със заглавие, описание и приоритет
- Автоматичен срок за реакция според приоритета (4/24/48 часа)
- Смяна на статус: отворена → в процес → затворена
- Филтриране по статус
- Запазване на заявките в `localStorage`
- Визуално отбелязване на просрочени заявки

## Ограничения

Това е демонстрационен frontend, без backend, база данни, регистрация или истински SLA мониторинг. Сроковете са примерни и се изчисляват от момента на създаване на заявката.
